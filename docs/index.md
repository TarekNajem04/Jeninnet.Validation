# Jeninnet.Validation

Jeninnet.Validation is a modular validation framework for .NET: attribute-driven and fluent
authoring, a compile-time source generator, deterministic execution, a zero-allocation happy path,
and optional integrations for ASP.NET Core, JSON Schema, OpenAPI, client rules, MediatR,
DataAnnotations, Blazor, and WPF/MAUI/Avalonia view models.
