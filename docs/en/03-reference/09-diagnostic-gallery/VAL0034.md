# VAL0034 — Invalid multiple-of divisor

| Field | Value |
|---|---|
| Severity | `Error` |
| Code fix | Intentional — see below |
| Constitution principle | III. Compile-Time Safe & Diagnostic-Rich |

A multiple-of rule uses a divisor that is zero, negative, NaN, or infinite. The rule cannot produce a meaningful result.

## Triggering code

```csharp
[Validate]
public sealed class Payment
{
    [MultipleOf(0)]
    public decimal Amount { get; set; }
}
```

## Compiler output

```text
error VAL0034: The divisor "0" for [MultipleOf] on "Amount" must be a positive finite number
```

## Why there is no automatic fix

The intended positive divisor is user intent; the generator cannot choose a replacement divisor.

## How to fix it

Use a positive finite divisor such as [MultipleOf(0.01)] for currency or [MultipleOf(5)] for a required increment.
