# VAL0001 — Invalid rule parameter

| Field | Value |
|---|---|
| Severity | `Error` |
| Code fix | Available — Converts the literal to the expected type; for a Boolean it removes the quotes. |
| Constitution principle | III. Compile-Time Safe & Diagnostic-Rich |

A rule attribute received a literal that cannot be converted to the member's type. The generator stops before it emits a rule that would fail at runtime.

## Triggering code

```csharp
[Validate]
public sealed class Feature
{
    [Equal("true")]
    public bool Enabled { get; set; }
}
```

## Compiler output

```text
error VAL0001: The value "true" cannot be parsed as type "Boolean" for rule "Equal"
```

## Fix

Converts the literal to the expected type; for a Boolean it removes the quotes.

## Fixed code

```csharp
[Validate]
public sealed class Feature
{
    [Equal(true)]
    public bool Enabled { get; set; }
}
```

## Why this is the fix

Use the literal form of the member type. The converter covers Boolean, DateOnly, DateTime, Decimal, Enum, Guid, and TimeSpan literals; it does not guess a value that the source does not contain.
