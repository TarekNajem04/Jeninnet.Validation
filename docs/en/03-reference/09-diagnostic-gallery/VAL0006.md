# VAL0006 — Rule cannot be used on nullable type

| Field | Value |
|---|---|
| Severity | `Warning` |
| Code fix | Available — Adds [NotNull] before the numeric rule so the generated validator rejects null explicitly. |
| Constitution principle | II. Declarative-First |

A numeric or comparison rule is applied to a nullable member. If null should be rejected, the declaration needs [NotNull] before the rule.

## Triggering code

```csharp
[Validate]
public sealed class Order
{
    [GreaterThan(0)]
    public int? Quantity { get; set; }
}
```

## Compiler output

```text
warning VAL0006: Rule "GreaterThan" cannot be applied to nullable type "int?" on the property "Quantity". Consider adjusting the rule "GreaterThan" or using a non-nullable type.
```

## Fix

Adds [NotNull] before the numeric rule so the generated validator rejects null explicitly.

## Fixed code

```csharp
[Validate]
public sealed class Order
{
    [NotNull]
    [GreaterThan(0)]
    public int? Quantity { get; set; }
}
```

## Why this is the fix

Keep the nullable member when null has meaning, but make the intent explicit: [NotNull] rejects null, while a non-nullable member makes null impossible by type.
