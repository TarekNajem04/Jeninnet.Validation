# VAL0029 — Conditional attribute has an invalid target

| Field | Value |
|---|---|
| Severity | `Error` |
| Code fix | Intentional — see below |
| Constitution principle | II. Declarative-First |

A conditional attribute references a sibling member that does not exist, is static, or cannot be read by the generated validator.

## Triggering code

```csharp
[Validate]
public sealed class Order
{
    [RequiredIf("Missing", 1)]
    public string? Code { get; set; }
}
```

## Compiler output

```text
error VAL0029: The conditional attribute "RequiredIf" on "Code" has an invalid target: no readable member "Missing" exists
```

## Why there is no automatic fix

The intended sibling member is user intent; the generator cannot know which member the author meant.

## How to fix it

Use nameof(...) with a readable instance member on the same model. Static members and self-references are rejected.
