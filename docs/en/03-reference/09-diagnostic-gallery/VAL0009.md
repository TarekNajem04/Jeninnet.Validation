# VAL0009 — Invalid rule combination

| Field | Value |
|---|---|
| Severity | `Error` |
| Code fix | Available — Raises the Length minimum to 1, or removes [NotEmpty] when the length rule is sufficient. |
| Constitution principle | II. Declarative-First |

Two rules imply incompatible minimum lengths. [NotEmpty] requires at least one character while [Length(0, …)] permits the empty string.

## Triggering code

```csharp
[Validate]
public sealed class User
{
    [NotEmpty]
    [Length(0, 100)]
    public string Name { get; set; } = string.Empty;
}
```

## Compiler output

```text
error VAL0009: Rule "NotEmpty" cannot be combined with rule "Length" on the same property "Name"
```

## Fix

Raises the Length minimum to 1, or removes [NotEmpty] when the length rule is sufficient.

## Fixed code

```csharp
[Validate]
public sealed class User
{
    [Length(1, 100)]
    public string Name { get; set; } = string.Empty;
}
```

## Why this is the fix

Keep one statement of the minimum length. [Length(1, 100)] already expresses the non-empty requirement.
