# VAL0005 — Collection element validator not found

| Field | Value |
|---|---|
| Severity | `Warning` |
| Code fix | Intentional — see below |
| Constitution principle | II. Declarative-First |

A [ForEach] collection points at an element type that has no generated validator, so the elements would not be validated.

## Triggering code

```csharp
[Validate]
public sealed class Order
{
    [ForEach]
    public List<LineItem>? Items { get; set; }
}

public sealed class LineItem
{
    public string? Sku { get; set; }
}
```

## Compiler output

```text
warning VAL0005: No validator was found for collection element type "LineItem"
```

## Why there is no automatic fix

The missing element validator must be authored; the generator cannot infer the element rules from the collection declaration.

## How to fix it

Annotate LineItem with [Validate], or use an explicit child validator through the fluent API.
