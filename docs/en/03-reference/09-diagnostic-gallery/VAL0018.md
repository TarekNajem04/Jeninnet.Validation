# VAL0018 — Invalid condition method

| Field | Value |
|---|---|
| Severity | `Error` |
| Code fix | Intentional — see below |
| Constitution principle | II. Declarative-First |

A conditional attribute names a method that is missing or has an unsupported signature.

## Triggering code

```csharp
[Validate]
public sealed class Order
{
    [WhenCondition("IsActive")]
    public string? Reason { get; set; }
}
```

## Compiler output

```text
error VAL0018: Condition method "IsActive" on type "Order" must be an accessible instance or static method matching (Order instance) or (Order instance, ValidationContext<Order> context)
```

## Why there is no automatic fix

The condition method must be authored or its signature chosen; the generator cannot provide business logic.

## How to fix it

Add an accessible method returning bool with (T instance) or (T instance, ValidationContext<T> context). Instance and static methods are supported.
