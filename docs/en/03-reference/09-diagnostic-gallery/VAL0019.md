# VAL0019 — Invalid lifecycle hook

| Field | Value |
|---|---|
| Severity | `Error` |
| Code fix | Intentional — see below |
| Constitution principle | II. Declarative-First |

A lifecycle attribute names a hook that is missing, non-static, or has the wrong return type or parameters.

## Triggering code

```csharp
[Validate]
[PreValidate("BeforeValidate")]
public sealed class Order
{
    public string? Number { get; set; }
}
```

## Compiler output

```text
error VAL0019: Lifecycle hook "BeforeValidate" on type "Order" must be a static method returning bool
```

## Why there is no automatic fix

The hook must be authored or its signature chosen; the generator cannot invent lifecycle behavior.

## How to fix it

Declare a static PreValidate method accepting (T, ValidationContext<T>) or (T, ValidationContext<T>, ValidationErrorCollector) and returning bool. OnFailure accepts ValidationResult and returns void.
