# VAL0030 — Conditional attribute value is not supported

| Field | Value |
|---|---|
| Severity | `Error` |
| Code fix | Intentional — see below |
| Constitution principle | II. Declarative-First |

The conditional constant cannot be compared with the target member's type.

## Triggering code

```csharp
[Validate]
public sealed class Order
{
    public bool IsActive { get; set; }

    [RequiredIf(nameof(IsActive), "yes")]
    public string? Reason { get; set; }
}
```

## Compiler output

```text
error VAL0030: The conditional attribute "RequiredIf" on "Reason" has an unsupported value: a Boolean member cannot be compared with "yes"
```

## Why there is no automatic fix

The intended comparison value is user intent; the generator cannot choose between changing the value and changing the member type.

## How to fix it

Match the constant to the sibling member's type: true for Boolean, a numeric literal for numeric types, and a parseable string for date/time, Guid, and TimeSpan members.
