# VAL0033 — Exclusive range has equal bounds

| Field | Value |
|---|---|
| Severity | `Error` |
| Code fix | Intentional — see below |
| Constitution principle | III. Compile-Time Safe & Diagnostic-Rich |

An exclusive range with equal bounds can never match. The declaration describes an impossible validation.

## Triggering code

```csharp
[Validate]
public sealed class User
{
    [ExclusiveBetween(5, 5)]
    public int Score { get; set; }
}
```

## Compiler output

```text
error VAL0033: [ExclusiveBetween] on "Score" has equal bounds (5); an exclusive range can never match. Widen the bounds or use an inclusive range.
```

## Why there is no automatic fix

Widening the bounds or switching to an inclusive range changes semantics; the author must choose the intended range.

## How to fix it

Use a strict lower < upper range such as [ExclusiveBetween(4, 6)], or use [InclusiveBetween(5, 5)] when the single value is intended.
