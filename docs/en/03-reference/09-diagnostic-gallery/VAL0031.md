# VAL0031 — Conditional attribute is duplicated

| Field | Value |
|---|---|
| Severity | `Error` |
| Code fix | Intentional — see below |
| Constitution principle | II. Declarative-First |

The same conditional attribute targets one member more than once, so the generated condition is ambiguous.

## Triggering code

```csharp
[Validate]
public sealed class Order
{
    public bool IsActive { get; set; }

    [RequiredIf(nameof(IsActive), true)]
    [RequiredIf(nameof(IsActive), false)]
    public string? Reason { get; set; }
}
```

## Compiler output

```text
error VAL0031: The conditional attribute "RequiredIf" on "Reason" targets "IsActive" more than once; combine the conditions or remove the duplicate
```

## Why there is no automatic fix

Which duplicate to keep is user intent; the generator cannot merge two different conditions safely.

## How to fix it

Keep one condition per attribute type and target. Different conditional attribute types may target the same member; their conditions are combined with AND.
