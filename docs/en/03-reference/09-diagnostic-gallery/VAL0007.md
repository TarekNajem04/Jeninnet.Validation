# VAL0007 — Conflicting rules on property

| Field | Value |
|---|---|
| Severity | `Error` |
| Code fix | Available — Removes one of the conflicting rules, leaving the author's remaining bound. |
| Constitution principle | II. Declarative-First |

Two bounds describe an impossible range, such as a value that must be greater than 100 and less than 50.

## Triggering code

```csharp
[Validate]
public sealed class User
{
    [GreaterThan(100)]
    [LessThan(50)]
    public int Age { get; set; }
}
```

## Compiler output

```text
error VAL0007: Property "Age" has multiple conflicting rules: GreaterThan(100) and LessThan(50) create an impossible range.
```

## Fix

Removes one of the conflicting rules, leaving the author's remaining bound.

## Fixed code

```csharp
[Validate]
public sealed class User
{
    [GreaterThan(100)]
    public int Age { get; set; }
}
```

## Why this is the fix

Choose the bound that expresses the real requirement. If the property truly needs a range, use [InclusiveBetween] or [ExclusiveBetween] with the intended lower and upper bounds.
