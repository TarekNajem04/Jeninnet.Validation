# VAL0017 — Tautological validation rule

| Field | Value |
|---|---|
| Severity | `Info` |
| Code fix | Available — Removes the always-satisfied attribute. |
| Constitution principle | II. Declarative-First |

The rule's bounds cover the full value range, so it can never fail. It adds cost without changing the result.

## Triggering code

```csharp
[Validate]
public sealed class User
{
    [MinimumLength(0)]
    public string Name { get; set; } = string.Empty;
}
```

## Compiler output

```text
info VAL0017: The rule "MinimumLength" on member "Name" is always satisfied and can be removed
```

## Fix

Removes the always-satisfied attribute.

## Fixed code

```csharp
[Validate]
public sealed class User
{
    public string Name { get; set; } = string.Empty;
}
```

## Why this is the fix

Keep the rule only when the explicit zero bound is useful documentation, and suppress the diagnostic locally with a reason in that case.
