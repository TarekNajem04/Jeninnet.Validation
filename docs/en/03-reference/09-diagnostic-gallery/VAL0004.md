# VAL0004 — Nested validator not found

| Field | Value |
|---|---|
| Severity | `Warning` |
| Code fix | Intentional — see below |
| Constitution principle | II. Declarative-First |

A [Nested] property points at a type that has no generated validator, so the nested rules would silently never run.

## Triggering code

```csharp
[Validate]
public sealed class Order
{
    [Nested]
    public Address? Address { get; set; }
}

public sealed class Address
{
    public string? Street { get; set; }
}
```

## Compiler output

```text
warning VAL0004: No validator was found for nested type "Address"
```

## Why there is no automatic fix

The missing nested validator must be authored; the generator cannot invent the rules for another model.

## How to fix it

Annotate the nested type with [Validate], or register a validator and reference it explicitly. A type without [Validate] has no generated validator to call.
