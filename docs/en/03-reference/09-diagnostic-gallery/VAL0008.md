# VAL0008 — Unsupported attribute argument type

| Field | Value |
|---|---|
| Severity | `Error` |
| Code fix | Intentional — see below |
| Constitution principle | II. Declarative-First |

An attribute argument has a CLR type that the rule cannot turn into a validation parameter.

## Triggering code

```csharp
[Validate]
public sealed class Order
{
    [Equal(typeof(string))]
    public string? Code { get; set; }
}
```

## Compiler output

```text
error VAL0008: Attribute argument "typeof(string)" is not supported for rule "Equal"
```

## Why there is no automatic fix

The supported argument contract depends on the rule's intended shape; the generator cannot choose a conversion that preserves the author's intent.

## How to fix it

Use a primitive, string, enum, or other rule-supported constant. If the value is genuinely a type, model that requirement with a custom rule.
