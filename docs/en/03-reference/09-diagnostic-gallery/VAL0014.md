# VAL0014 — Redundant [NotNull] attribute

| Field | Value |
|---|---|
| Severity | `Warning` |
| Code fix | Available — Removes the redundant [NotNull] while keeping sibling validation attributes. |
| Constitution principle | II. Declarative-First |

[NotNull] is applied to a non-nullable value type, where it cannot change the result.

## Triggering code

```csharp
[Validate]
public sealed class User
{
    [NotNull]
    public int Age { get; set; }
}
```

## Compiler output

```text
warning VAL0014: The property "Age" is non-nullable; [NotNull] is redundant and can be removed
```

## Fix

Removes the redundant [NotNull] while keeping sibling validation attributes.

## Fixed code

```csharp
[Validate]
public sealed class User
{
    public int Age { get; set; }
}
```

## Why this is the fix

Keep [NotNull] on nullable reference or value types where it expresses a real requirement. On a non-nullable value type it is noise.
