# VAL0022 — Model shape is not supported

| Field | Value |
|---|---|
| Severity | `Error` |
| Code fix | Intentional — see below |
| Constitution principle | I. Library-First & Source-Generated |

The source generator cannot emit a validator for this model shape. It fails closed instead of producing a partial or misleading validator.

## Triggering code

```csharp
[Validate]
public sealed class Box<T>
{
    [NotEmpty]
    public string? Name { get; set; }
}
```

## Compiler output

```text
error VAL0022: Type "Box<T>" cannot be validated by the source generator: generic models are not supported; use a non-generic model or a fluent validator
```

## Why there is no automatic fix

The model shape must change or move to a fluent validator; a generator fix would have to choose a closed instantiation, namespace, or instance member.

## How to fix it

Use a non-generic model with an explicit namespace and instance properties, or write a fluent validator for the unsupported shape. Global-namespace models and static validated properties report the same descriptor.
