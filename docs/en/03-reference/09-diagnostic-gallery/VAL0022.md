# VAL0022 — Generic model is not supported

| Field | Value |
|---|---|
| Severity | `Error` |
| Code fix | Intentional — see below |
| Constitution principle | I. Library-First & Source-Generated |

The source generator emits closed, non-generic validator classes and cannot generate a validator for an open generic model.

## Triggering code

```csharp
[Validate]
public sealed class Box<T>
{
    [NotEmpty]
    public string? Name { get; set; }
}
```

## Compiler output

```text
error VAL0022: Generic type "Box<T>" cannot be validated by the source generator; use a non-generic model or a fluent validator
```

## Why there is no automatic fix

The model shape must change or move to a fluent validator; a generator fix would have to choose a closed instantiation.

## How to fix it

Use a non-generic model, or write a fluent Validator<Box<T>> for the closed generic type you actually validate.
