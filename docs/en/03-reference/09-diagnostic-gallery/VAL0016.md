# VAL0016 — Synchronous Validate on async-only validator

| Field | Value |
|---|---|
| Severity | `Warning` |
| Code fix | Available — Rewrites the call to await ValidateAsync(...). |
| Constitution principle | III. Compile-Time Safe & Diagnostic-Rich |

A validator marked [AsyncOnlyValidator] is called through the synchronous API, which would throw at runtime.

## Triggering code

```csharp
public sealed class OrderService
{
    public void Check(IValidator<Order> validator, Order order)
    {
        var result = validator.Validate(order);
    }
}
```

## Compiler output

```text
warning VAL0016: "OrderService" is marked [AsyncOnlyValidator]; synchronous Validate() throws at runtime, use ValidateAsync() instead
```

## Fix

Rewrites the call to await ValidateAsync(...).

## Fixed code

```csharp
public sealed class Order { }

public sealed class OrderService
{
    public async Task<ValidationResult> CheckAsync(IValidator<Order> validator, Order order) =>
        await validator.ValidateAsync(order);
}
```

## Why this is the fix

Use the async path for async-only validators. If the call site must stay synchronous, add a synchronous rule to the validator instead of suppressing the warning.
