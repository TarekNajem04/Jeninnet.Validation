# VAL0013 — Rule can be simplified

| Field | Value |
|---|---|
| Severity | `Info` |
| Code fix | Intentional — see below |
| Constitution principle | II. Declarative-First |

Two comparison rules describe one range. A single range rule is shorter and keeps the lower and upper bounds together.

## Triggering code

```csharp
[Validate]
public sealed class User
{
    [GreaterThan(0)]
    [LessThan(10)]
    public int Score { get; set; }
}
```

## Compiler output

```text
info VAL0013: The process of validating the property "Score" can be simplified by using "'InclusiveBetween' or 'ExclusiveBetween'" instead of "'GreaterThan' and 'LessThan'"
```

## Why there is no automatic fix

Replacing two rules with one changes the documented rule set and may change inclusive/exclusive semantics; the author must choose the replacement.

## How to fix it

For integer values greater than 0 and less than 10, use [InclusiveBetween(1, 9)] or [ExclusiveBetween(0, 10)] depending on the values the domain allows.
