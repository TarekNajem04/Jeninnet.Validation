# VAL0012 — Consider adding [NotNull] for nullable property

| Field | Value |
|---|---|
| Severity | `Info` |
| Code fix | Available — Adds [NotNull] next to the nullable member's rule. |
| Constitution principle | II. Declarative-First |

A nullable member has validation rules but no explicit null decision. The suggestion makes that decision visible.

## Triggering code

```csharp
[Validate]
public sealed class User
{
    [Email]
    public string? Email { get; set; }
}
```

## Compiler output

```text
info VAL0012: Property "Email" is nullable and has validation rules; consider adding [NotNull]
```

## Fix

Adds [NotNull] next to the nullable member's rule.

## Fixed code

```csharp
[Validate]
public sealed class User
{
    [NotNull]
    [Email]
    public string? Email { get; set; }
}
```

## Why this is the fix

Add [NotNull] when null is invalid. Leave the member nullable and omit the attribute when null means the rule should be skipped.
