# VAL0028 — SkipValidation conflicts with validation attributes

| Field | Value |
|---|---|
| Severity | `Warning` |
| Code fix | Intentional — see below |
| Constitution principle | II. Declarative-First |

[SkipValidation] drops every rule for the property, so the accompanying validation attributes never run.

## Triggering code

```csharp
[Validate]
public sealed class Order
{
    [SkipValidation, NotEmpty]
    public string? Code { get; set; }
}
```

## Compiler output

```text
warning VAL0028: [SkipValidation] on "Code" is combined with validation attributes; remove the attributes or the skip marker
```

## Why there is no automatic fix

Removing the skip marker or removing the attributes depends on the author's intent; both are valid outcomes.

## How to fix it

Keep [SkipValidation] and remove the validation attributes to opt out deliberately, or remove [SkipValidation] to let the rules run.
