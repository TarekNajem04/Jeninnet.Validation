# VAL0024 — Collection rule requires a collection

| Field | Value |
|---|---|
| Severity | `Warning` |
| Code fix | Intentional — see below |
| Constitution principle | III. Compile-Time Safe & Diagnostic-Rich |

A cardinality rule such as Count, MinCount, or MaxCount is applied to a scalar member.

## Triggering code

```csharp
[Validate]
public sealed class Order
{
    [Count(1, 5)]
    public int CountValue { get; set; }
}
```

## Compiler output

```text
warning VAL0024: Rule "Count" requires a collection, but the target type is "int"
```

## Why there is no automatic fix

The target member or the rule must change based on intent; the analyzer cannot know which one the author meant.

## How to fix it

Apply cardinality rules to arrays or IEnumerable<T> members. Use [InclusiveBetween] for a numeric scalar or remove the cardinality rule.
