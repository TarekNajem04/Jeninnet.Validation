# VAL0020 — Invalid custom validator

| Field | Value |
|---|---|
| Severity | `Error` |
| Code fix | Intentional — see below |
| Constitution principle | II. Declarative-First |

A [CustomValidator] reference names a method that is missing or does not match a supported synchronous or asynchronous signature.

## Triggering code

```csharp
[Validate]
public sealed class Order
{
    [CustomValidator(typeof(OrderRules), "Validate")]
    public string? Number { get; set; }
}

public static class OrderRules { }
```

## Compiler output

```text
error VAL0020: Custom validator method "Validate" on type "OrderRules" must be a static method matching a supported signature
```

## Why there is no automatic fix

The custom method must be authored or its signature chosen; the generator cannot guess the validation logic.

## How to fix it

Use a static method returning bool or ValidationResult and accepting (TValue) or (TValue, IServiceProvider). Async methods set IsAsync = true, return ValueTask<bool> or ValueTask<ValidationResult>, and end with CancellationToken.
