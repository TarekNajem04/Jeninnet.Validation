# VAL0011 — Consider adding [NotEmpty] for string property

| Field | Value |
|---|---|
| Severity | `Info` |
| Code fix | Available — Adds [NotEmpty] next to the existing string rule. |
| Constitution principle | II. Declarative-First |

A string participates in validation but has no explicit empty-string decision. The analyzer suggests making that decision visible.

## Triggering code

```csharp
[Validate]
public sealed class User
{
    [Length(3, 100)]
    public string Name { get; set; } = string.Empty;
}
```

## Compiler output

```text
info VAL0011: Property "Name" is a string and participates in validation; consider adding [NotEmpty]
```

## Fix

Adds [NotEmpty] next to the existing string rule.

## Fixed code

```csharp
[Validate]
public sealed class User
{
    [NotEmpty]
    [Length(3, 100)]
    public string Name { get; set; } = string.Empty;
}
```

## Why this is the fix

Add the attribute when the empty string is invalid. Keep the suggestion off when empty is a meaningful value, or configure the rule's message to explain that choice.
