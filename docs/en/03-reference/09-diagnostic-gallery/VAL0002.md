# VAL0002 — Rule applied to incompatible property type

| Field | Value |
|---|---|
| Severity | `Error` |
| Code fix | Intentional — see below |
| Constitution principle | II. Declarative-First |

The attribute describes a check that the member's type cannot support. The generator refuses to emit an impossible rule.

## Triggering code

```csharp
[Validate]
public sealed class User
{
    [Email]
    public int Id { get; set; }
}
```

## Compiler output

```text
error VAL0002: Rule "Email" cannot be applied to property "Id" of type "int"
```

## Why there is no automatic fix

Changing the rule or changing the member type are both valid designs. An automatic fix would have to guess which one the author intended.

## How to fix it

Use a string member for [Email], or choose a rule that matches the numeric member (for example [GreaterThan]).
