# VAL0015 — Target property not found

| Field | Value |
|---|---|
| Severity | `Error` |
| Code fix | Intentional — see below |
| Constitution principle | II. Declarative-First |

A property-comparison rule references a sibling member that does not exist on the model.

## Triggering code

```csharp
[Validate]
public sealed class User
{
    [PropertyEqual("Password")]
    public string? ConfirmPassword { get; set; }
}
```

## Compiler output

```text
error VAL0015: Rule "PropertyEqual" references a property "Password" that does not exist on type "User"
```

## Why there is no automatic fix

The intended sibling member name is user intent; the generator cannot know which member was meant.

## How to fix it

Use nameof(Password) in fluent code, or correct the attribute string. The comparison target must be a readable member on the same model.
