# Localization — Memory Sample

Demonstrates Jeninnet.Validation localization with in-memory message dictionaries.

## Highlights

- `MemoryMessageProvider` instances with inline per-culture dictionaries (en, nl, fr, de)
- `CultureAwareMessageProvider` resolves the culture hierarchy at lookup time
- End-to-end validation with localized error messages

## Package References

- Jeninnet.Validation
- Jeninnet.Localization.Core
- Jeninnet.Localization.Providers.Memory
- Jeninnet.Validation.Sample.Localization.Base

## Run

```bash
dotnet run --project samples/Jeninnet.Validation.Sample.Localization.Memory
```
